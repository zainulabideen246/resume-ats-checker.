# 📄 AI Resume ATS Checker & Optimization App

An AI-powered Applicant Tracking System (ATS) analyzer built using **Streamlit** and **Google's Gemini 1.5 Flash**. This tool compares candidate resumes against job descriptions, outputs an ATS compatibility match score, identifies missing keywords, and gives actionable recommendations for resume improvement.

## 🌟 Features
* **PDF Parsing**: Extracts clean text content directly from PDF resume uploads.
* **ATS Match Score**: Computes compatibility percentage based on candidate alignment.
* **Skill Gap Identification**: Pinpoints missing technical and soft skills.
* **Actionable Suggestions**: Provides clear bullet-point improvements to optimize resume bullet points.

## 🛠️ Tech Stack
* **Frontend/UI**: Streamlit
* **AI Model**: Google Gemini 1.5 Flash via `google-genai` SDK
* **PDF Parsing**: `pdfplumber`
